CASOS DE USO AHORA SOPORTADOS:
═══════════════════════════════════════════════════════════════════════════

Caso 1: Usuario Completa Quiz en Una Sesión
  → Responde, envía, ve explicaciones, vuelve

Caso 2: Usuario Abandona Quiz a Mitad
  → Vuelve al módulo, progreso se guarda
  → Cierra navegador, vuelve después
  → Quiz continúa desde pregunta 5/10

Caso 3: Usuario Quiere Repasar
  → Accede módulo, ve "Continuar Quiz"
  → Hace clic "Reiniciar Quiz"
  → Comienza de nuevo, respuestas anteriores se borran

Caso 4: Usuario Quiere Mejora
  → Lee explicaciones de respuestas incorrectas
  → Vuelve a leer módulo
  → Reinicia quiz y lo intenta nuevamente

Caso 5: Usuario Salta Preguntas
  → Clickea en número 7
  → Salta a pregunta 7
  → Continúa respondiendo

LÍMITES Y CONSIDERACIONES:
  • localStorage: ~5-10MB máximo (suficiente para este sistema)
  • Datos guardados por navegador (no se sincronizan entre dispositivos)
  • Datos persisten mientras no se limpie localStorage
  • No requiere conexión a internet después de cargar

RENDIMIENTO:
  • Carga instantánea de progreso
  • Guardado sin bloqueos (asincrónico implícito)
  • Re-renderizado eficiente
  • Sin lag perceptible en navegadores modernos
